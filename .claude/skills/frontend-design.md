# Frontend Design Workflow

Before implementation:

1. Read CLAUDE.md.
2. Inspect existing relevant screens.
3. Inspect existing components.
4. Understand the user goal.
5. Identify the primary action.
6. Identify loading, empty, error and success states.
7. Determine responsive behavior.

## Design Constraints

Use the existing design system.

Prefer shadcn/ui and existing application components.

Do not invent a new visual language.

## Implementation

Build the smallest coherent solution that satisfies the product requirement.

Reuse existing components whenever possible.

## Quality Pass

After implementation:

1. Review visual hierarchy.
2. Review spacing.
3. Review typography.
4. Review responsiveness.
5. Review interaction states.
6. Review accessibility.
7. Remove unnecessary decoration.

The result must feel like one cohesive product.
